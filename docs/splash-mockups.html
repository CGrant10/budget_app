Splash screen revamp

The splash animation was written for a 4.2 second hold. Now that launch takes about a second, the wordmark (finishes 1.02s), tagline (1.18s) and progress bar (2.10s) are all still arriving when the fade-out starts at 900ms — so you see the dog land and then everything else leave mid-entrance. Nothing here changes how long launch takes; all four dismiss at the same 900ms. Only the choreography inside that window differs.

The dashboard fades in underneath, as it does in the real app.
