Settings reorganisation

Today it's 9 flat cards in one scroll, and anything to do with how the app looks is spread across four of them — Theme, Font, Animations and Appearance. All three mockups use the same regrouping; they differ only in how you get to it. Same phone-sized frame in each, so the scroll length is directly comparable.

Today9 cards, flat

For comparison. Every card expanded, no grouping — the whole page is one scroll.

A · Collapsed groupsLeast work

Five groups, all shut by default — the whole page fits without scrolling. Tap one to open it in place. No navigation to build, and you never lose your place.

B · Index and subpagesEasiest to scan

A short menu; each group is its own page with a back link. Closest to how phone settings work, so it needs no explaining — but it adds a real navigation layer.

C · Search firstFastest when you know

Groups stay open, with a filter at the top — type "pin", "skin", "mascot". Fastest if you know the name, but the page is still long when you don't. Try typing in it.

D · Collapsed + searchRecommended

A and C combined. Shut and one screen when you arrive; start typing and the groups holding matches open themselves while the rest disappear. Clear the box and it shuts again. Search covers keywords too — try blur, dark, fingerprint or fake, none of which appear in any label.
