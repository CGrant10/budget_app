Putting Gengar in the clean skins

The sprite is playful, purple and 74×63. The skins are restrained, typographic and mostly monochrome. Dropped in as-is at some arbitrary size it reads as clip art — so each option below gives it a job, and picks one of two honest registers.

The rule that makes this work: either the sprite is a silhouette — one flat skin colour via CSS mask, so it behaves like an icon and can go large — or it's an artifact: full colour, small, and scaled by a whole number (2× = 148×126, 3× = 222×189) so the pixels stay razor-sharp. Full colour and large is the combination that fights the design. Both assets are ~57% transparent, so their alpha masks cleanly.

01

Ink watermark

silhouette · 5–8% opacity · bleeds off the card

Gengar as a large, barely-there silhouette behind the balance, clipped by the card edge. Painted in the skin's own ink, so it reads as paper texture rather than a character. You notice it on the second look, which is exactly the point.

✓ Recommended. Adds identity with zero cost to legibility, and survives all three skins.

  1. 05 hidden-balance first — it's the only one that carries meaning, and it's ~15 lines.
  2. 03 nav mark — puts the mascot back in the bar you found odd, at icon weight.
